## The joke

> The AI wrote the code, reviewed the code, and merged the code — I just pay the API bill.

## How it works

`main.ts` (Node 22, stdlib only, no network) writes exactly that one line,
plus a trailing newline, to `/output/entry.txt`. It guards the gate first:
the text must be 1–280 Unicode code points, non-blank, and a single line.

Run it:

```sh
node main.ts
```
